# Specification Index

This directory documents externally visible behavior for `xdg-thumbnail` components and packaged artifacts.

- `cleanup-policy.md`: cleanup classification, deletion policy, timestamp basis, and deletion reasons.
- `generate-cli-behavior.md`: `xdg-thumbnail-generate` command-line contract, reporting, exit codes, and safety requirements.
- `library-api.md`: public library API contract.
- `package-artifacts.md`: installed package artifacts beyond CLI binaries, including generated metadata and systemd user units.
- `prune-cli-behavior.md`: `xdg-thumbnail-prune` command-line contract, reporting, exit codes, and safety requirements.
- `uri-canonicalization.md`: URI normalization and hashing contract.
